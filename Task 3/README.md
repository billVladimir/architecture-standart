Опишите здесь наиболее важные альтернативные решения.

| Альтернатива                                      | Причина отклонения                                                                |
| ------------------------------------------------- | --------------------------------------------------------------------------------- |
| Использовать **прямую интеграцию ИБ → АБС**       | АБС перегружена, прямой доступ создаёт риски по производительности и надёжности   |

| Реализовать всё в рамках текущего монолита ИБ     | Увеличивает связность и сложность, затрудняет масштабирование, требует подрядчика |
| Использовать внешнюю систему расчёта ставок       | Увеличивает сложность, требует отдельной интеграции и потенциальные лицензии      |
